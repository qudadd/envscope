# 桌面界面

0.7 在实际试用步骤内加入打开与正常重开的入口。启动条件收起展示，结果与具体原因
留在按钮下方；不增加导航、卡片或第二个首页主按钮。打开请求不显示为登录成功。

0.6 使用一个主按钮和一条四步进度线：检测、核对方案、修复复检、日常保持。
环境选项默认收起，开始检测后收起并锁定至本轮完成。自动生成的具体方案成为主内容，
确认按钮与备份撤销保留在当前页。分项状态移入技术记录；同页提供长期保持的预览、
启用与停用。黑白、系统字体、细分隔线不变，不新增卡片或装饰组件。

0.5 保留黑白、系统字体和窄侧栏，改为任务顺序：首次教学 → 检查 → 处理 → 实际试用 → 日常保持。
教学是正常页面，三步可退回、跳过和重看；使用范围只在开始检测时保存。
首页先展开一项最优先问题；其余问题、14 项白话核对和完整技术记录按需要展开。
白话核对解释查什么、为何影响使用、现在是否要动以及怎样保持，不以术语作为主标题。
手动试用确认、网络探测与后台状态分别显示，重新检测清除旧的本页试用确认。
后台页直接呈现最近执行时间、问题数、恢复受阻原因、方案及事件，不展示原始 JSON。
未注册、等待首轮、超期、失败和已完成不能使用同一种成功提示。

EnvScope 是供普通用户排查 Claude 环境的本机工具。主要任务是启动一次检测、理解需要处理的项目，再进入账号或维护操作。Windows 和 macOS 是本阶段的适配范围。

采用安静的桌面工具布局：固定的窄导航，左对齐的正文，清晰的单个检测按钮。完成后直接呈现具体问题、事实、原因、步骤和入口。审核改动、确认执行和复检留在当前页。原始证据用于导出，不要求用户展开 JSON 自行归因。

```text
EnvScope        环境检测                         一键检测
版本            检测范围和本次状态

检测            问题概览                         一站式处理
账号            本次方案                         确认执行
工具            具体问题 / 原因 / 步骤             处理入口
历史            复检结果                          撤销修改
设置            检查记录与检测边界                 导出
```

视觉变量：纸面白 `#ffffff`，导航灰 `#f7f7f7`，正文黑 `#202020`，辅助文字 `#646464`，分隔线 `#e6e6e6`，当前导航 `#eaeaea`。黑底只用于主要操作；状态同时通过文字与字重区分。无品牌强调色、卡片、阴影、渐变、装饰图标或大号数字。

字体使用操作系统的界面字体，Windows 优先 Segoe UI / Microsoft YaHei UI，macOS 优先系统字体 / PingFang SC；字号 12、13、14、18、26。说明文字的对比度和宽度优先于极小字号。代码与证据才使用等宽字体。

导航宽 192 像素；正文最大 1104 像素，内边距 40 像素。按钮与输入框用 5 像素圆角表达可操作性。分隔线只用于分组与列表。交互即时，无装饰动画；键盘焦点可见，处理方案和复检完成后定位到对应内容。

复核：拒绝暖色纸面、营销标题、状态卡片和多余编号；调整原界面的过小字体与漫长的等待列表。通过真实页面截图检查初始、检测、账号、工具、历史和设置页面，并在 1024、1280、1440 像素桌面宽度检查溢出。

设计过程参考已安装的 Anthropic [frontend-design](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/frontend-design) Skill。它是开发工具，不随 EnvScope 分发，也不属于运行依赖。
