# 桌面界面

0.24 将首页收敛为一条流程：确认地区与时区、检测、查看问题与修复方案、启用持久化守护。面向 Windows 和 macOS，暂不适配手机端。

顶部仅保留 EnvScope、版本、检测与修复、“更多功能”。原有账号、全部检查、工具、历史和高级维护完整保留在菜单中。首页不显示空的结果表；首次使用以简短行内提示引导填写目标，完整教学可从页脚重看。

地区设置默认显示实际使用地区、节点地区、城市 / 时区所在地和目标时区。选择城市自动匹配地区格式与语言；用途、连接方式和其他要求折叠。节点地区依据出口建议，用户手动选择优先，实际所在地独立填写。

检测后，所有问题标题、观测和处理方式逐项可见。展开一项可查看原因与步骤；缺少必需证据也必须有明确入口。不能自动修复的项目用红色文字说明。技术记录、已通过的观测与帮助默认折叠。

修复区先列具体改动，只保留一个确认修复并复检按钮。持久化守护紧随其后：选择间隔与需保持的配置，预览、确认、启停都在同页。后台权限或修复失败必须显示原因，不能仅凭写入成功就显示环境合格。

```text
EnvScope   版本                       检测与修复    更多功能

Claude 环境检查                                  一键检测
地区与时区                                      调整目标

目标环境结论                            全部检查与证据
具体问题 / 当前值与目标 / 处理方式

修复方案
具体改动 → 确认修复并复检

持久化守护
周期 / 保持范围 → 预览守护方案

详细记录与使用帮助（按需展开）
```

视觉使用白、灰、黑及手动处理的红色文字。系统字体、细分隔线、可见键盘焦点；黑底仅用于主要操作。无渐变、阴影、装饰图标、营销标题或状态卡片。正文居中、最大 1040 像素，桌面内边距 40 像素。

主流程和菜单在 1024、1280、1440 宽度通过隔离浏览器测试与截图检查；代理、时区和守护均使用一次性模拟数据。截图不能作为真实 Claude 登录或网络可用的证据。详见 [流程与地区覆盖](SIMPLE_WORKFLOW.md)。

设计参考已安装的 Anthropic [frontend-design](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/frontend-design) Skill。它是开发工具，不随 EnvScope 分发。
