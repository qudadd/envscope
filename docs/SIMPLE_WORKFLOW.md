# 简化的一键流程（0.24）

首页只按实际操作顺序展示四个部分，保留黑白、系统字体和桌面宽度。

1. **地区与时区**：填写实际所在地；读取当前出口 IP，建议节点地区及对应城市。选择城市会匹配 Windows / macOS 时区、地区格式和语言目标。手动选择和已保存目标不会被迟到的查询结果覆盖。用途与连接方式按需展开。
2. **一键检测**：完成目标确认后开始。结果说明必需项通过、不合格和待完成的数量；所有问题标题、实际观测与处理方式直接可见。需要权限、缺少证据和本版不支持的检查分别说明，不计为通过。
3. **修复方案**：先列出具体字段、原值与目标或可执行操作。时区、地区格式与 Code 配置合并审核，确认后才执行，随后自动复检。复检使旧方案失效，再按当前问题生成新方案；重新生成入口始终保留。方案生成失败可重试，检测失败时说明需要先重新检测。上次执行结果、失败原因、备份和恢复入口独立保留；部分失败不会重复自动执行，需核对恢复记录。需要先启动客户端的操作仍分阶段复检；无法自动处理的项目标红并给出步骤。
4. **持久化守护**：选择周期以及需要保持的时区、地区格式和代理；额外客户端与 Code 选项折叠。预览具体基线并确认启用，同页可停用。后台仅执行已批准的范围并保存结果，未获得权限的修改保留原因。首页显示最近完成时间和各项基线的实际恢复结果；失败、过期或暂停以红色提示，完整日志在“更多功能 → 守护与高级修复”。

顶部“更多功能”提供全部检查（选择 / 全选 / 批量处理）、账号资料、工具与备份、守护与高级修复、历史、设置与更新、环境全览。详细测量、帮助和 Claude 启动入口放在首页末尾，不妨碍主流程。

## 地区覆盖

保留原有预设 ID，补充 Unicode CLDR 48 数据，合计 417 个城市 / 时区预设，覆盖 247 个国家和地区；地区名称目录另包含无时区映射的历史或特殊地区，这些地区明确提供自定义入口。城市列表是时区代表地点，不是完整地名库；同一国家的其他城市可选对应时区或手动填写。

数据固定于 CLDR 提交 `acd6d88ae493633240e19a87a721076a8a75c310`，生成器校验源文件 SHA256，随包离线提供。来源、许可和再生成脚本见 [第三方声明](../THIRD_PARTY_NOTICES.md)、[生成器](../scripts/generate_region_data.py)。IP 时区别名可匹配相同国家的预设；部分或失败的查询要求手动选择。

节点地区是出口与配置目标；实际所在地仍单独填写。地区预设不改变 Claude 官方服务支持条件，CN / RU 的现有地区检查继续保留。时区与语言配置本身不保证账号可用或服务端设备判断。

## 验收范围

`scripts.simple_workflow_smoke` 使用一次性配置、模拟 Windows / macOS 系统和替代调度器，检查首次提示、地区选择、问题内复检生成新方案、过期方案拒绝写入、生成失败重试、复检失败恢复、权限拒绝后的手动恢复、守护启停及全部导航。模拟时区与地区格式漂移后，调用真实守护逻辑，核对恢复读回、日志和首页结果。1024、1280、1440 桌面宽度检查溢出。Code 测试另覆盖损坏 JSON 与证书设置一次修复、已有字段保留和未选择范围拒绝写入。

以上为隔离验收，不修改测试机器的真实时区、代理、账号或后台任务，也不代表 Claude 实际认证已通过。
