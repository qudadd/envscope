# 实施路线

## 0.1：完整功能底座与日常工具

已实现：Windows / macOS 采集适配、五页极简桌面界面、14 类检查、系统与浏览器一键合并、IPv4/IPv6 独立策略、原生 STUN 校验、代理配置发现与连接诊断、50 次脱敏历史 / 比较、诊断包、偏好保存 / 恢复、事务式动态账号槽位与切换前重检。

完整保留原版 57 个源码文件及许可；固定适配器接入安装、修复、守护、路由迁移与维护核心更新，macOS 另外接入系统地区、代理客户端、临时浏览器和加密 DMG。这些操作是独立安装的原版功能，原版输出不构成独立测量。Windows 新增 CLI 安装位置与设备 / 字体信息，浏览器信息按需在本页生成。

发布门槛：完成来源与许可核对、桌面交互检查、Windows 包验证，并在说明中保留 DNS、路由关联与防火墙能力缺口。手机端与 Linux 不作为当前产品适配目标。

## 下一步：平台功能与实际路径证据

0.2 已实现系统解析、按地址族查询目标选路、hosts / 代理差异 / 绕过 / 监听、TLS / 时差 / 分段耗时、客户端及 CLI 配置、磁盘空间和账号结构检查，共 18 项扩展。守护任务停用 / 未运行不再通过。系统选路没有替代下面的目标进程关联工作。

| 模块 | 实现要点 | 验收条件 |
|---|---|---|
| 权威 DNS 观测 | 自有域名、随机不可复用子域名、短时会话、权威侧查询源记录 | 正常、分流、缓存、无查询均有可复现结果；DoH 可达不能替代该结果 |
| 目标流量关联 | 目标域名解析、系统路由选择、进程/套接字与网卡关联 | 能区分虚拟网卡存在和目标流量实际经过该网卡 |
| Windows 功能延伸 | 原生加密快照、临时浏览器、地区 / 客户端系统适配 | 不把未加密复制或本机偏好保存宣称为对应功能已完成 |
| 原生维护替换 | 从固定原版适配逐步迁移到可预览、可恢复的跨平台操作 | 原版功能不丢失，每项有失败回滚与隔离设备验证 |
| 产品更新与驻留 | 签名整包更新、系统托盘 / 菜单栏 | 完整性、回滚、退出和后台行为明确 |
| macOS 真机 | Intel / Apple Silicon，Safari / Chrome | 双击、首次启动、检测、导出和退出均可复核 |

## 后续：故障场景与防护验证

在隔离虚拟机或明确选择的测试设备中，验证断线、网络切换、DNS 改变、睡眠恢复、IPv6 恢复和代理重启。观测网络层数据包，而非只看进程是否被终止。

Windows 防火墙/WFP 与 macOS pf 必须独立评估。任何保护功能都需要明确范围、恢复路径和抓包验收；常规“一键检测”继续只读，不能通过点检测按钮改动系统网络。

没有验证通过的防护模块不进入已支持能力清单。第一阶段没有“零泄漏”保证、账号安全评分或封禁风险预测。
