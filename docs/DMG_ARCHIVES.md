# 加密账号备份与原版 DMG 兼容

在账号页选择备份格式，然后选择槽位、文件和密码。导出前先切换到其他账号；
导入只写入空的非活动槽位。所有操作均需确认，导入不启动 Claude，不调用登出接口。

| 格式 | 平台和槽位 | 校验范围 |
|---|---|---|
| `.envsnap` | Windows / macOS，任意有效槽位 | AES-256-GCM 认证加密、完整文件清单、复制读回 |
| 原版 `.dmg` | macOS，A–D，导入须为原槽位 | 加密状态、hdiutil 映像校验和、格式标记、复制读回；旧存档没有逐文件清单 |
| EnvScope 导出的 `.dmg` | macOS，A–D，可由原版读取 | 上述范围，另加嵌入标记的文件清单和导出后实际解密回读 |

新备份密码至少 12 字符。原版 DMG 导入接受原密码，包括旧版 8 字符密码。
DMG 密码不得含换行或空字符。密码仅通过标准输入交给固定的 `/usr/bin/hdiutil`，
不进入命令行、配置或日志。DMG 的映像校验和不是认证加密，也不是发布者签名。

## 完成与失败

先把非活动账号复制到权限受限的暂存目录，创建 AES-256 DMG，实际挂载回读并比较
所有目录、文件长度和 SHA-256，再通过同目录临时文件独占发布，不覆盖已有导出文件。
不支持硬链接发布的目标文件系统会拒绝导出，可选择本机磁盘后重试。

导入先校验复制到私有目录的源映像，确认加密，检查映像校验和，再只读挂载。
格式、原槽位、文件数量、总体积、特殊文件、链接和可用清单均通过后才复制。
复制读回一致并确认卸载后，通过 AccountManager 导入空槽位。未完成账号事务仍会阻止导入。
上限为单个映像 8 GiB、资料 8 GiB、200000 项。

如果程序中断或系统拒绝卸载，暂存目录会保留。下次打开账号页会标红并显示
“检查并清理暂存”。确认后只针对自己暂存的映像核对设备、卸载并再次读取挂载状态，
确认无挂载点才删除暂存副本。无法核实设备或出现外部变动时停止，使用 macOS
磁盘工具检查并推出 `ClaudeSnapshot-*`。原备份、导出文件及账号槽位保留。
如失败发生在数据提交后，先查看账号和文件状态，避免误认为操作完全没有发生。

事件按日追加到 `~/.envscope/dmg-work/events/*.private.jsonl`，记录事务、阶段和槽位，
不记录密码、源/目标文件路径或凭据内容。暂存目录是 `~/.envscope/dmg-work/dmg-*`。
正常清理不是磁盘安全擦除，操作系统交换文件、快照及其他备份不在清理范围内。

## 兼容契约与验证

契约取自固定上游
[`snapshot_export` / `snapshot_import`](https://github.com/YOURSJEYO/claude-switcher/blob/870c4ca0754234965878ef58144d7a755d965037/core/claude-switch.sh)：
资料位于映像根目录；`.claude-switcher-snapshot.json` 的 `format` 为
`claude-switcher-snapshot`、`version` 为整数 1、`account` 为 A–D。
EnvScope 的清单位于同一个标记的扩展字段内，原版读取器会忽略它并移除标记，
不会把额外清单文件混入账号目录。挂载产生的 `.fseventsd`、`.Trashes`、
`.Spotlight-V100`、`.TemporaryItems` 不导入；账号原来含这些保留名称时拒绝 DMG 导出，
可使用 `.envsnap`。

`tests/test_dmg_archive.py` 使用模拟挂载器验证失败、中断、占位、权限确认及日志范围。
`scripts/coverage_smoke.py` 在 1024、1280、1440 宽度验证格式选择、错误、清理和再次导入。
`scripts/dmg_acceptance.py` 在 Mac CI 实际调用系统工具，创建旧布局夹具、原生加密
往返、错误密码与未加密拒绝、原版根目录读取、卸载与清理；保留本机 Apple 手册作为
开发验证资料。两种 Mac 架构的冻结软件也用临时账号执行真实加密往返。
发布时需同时检查 DMG、native、update 三组证据；模拟通过不代表 Mac 实机通过。

这是本地资料存档。系统钥匙串、系统凭据库、服务端会话、订阅和设备识别均不由
资料目录完整性证明。真实账号迁移、跨系统认证和服务端设备稳定性仍需另行验收。
