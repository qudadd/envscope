# 环境全览与功能范围

[新用户指南](USER_GUIDE.md) · [完整功能对照](FULL_PARITY_AUDIT.md) · [文档目录](README.md)

0.25.0 的检查目录共 **57 项**，包含 14 类基础、19 项扩展，以及目标条件、设备资料和
补充测量。目录数量不是独立实验数量，也不代表每种用途都需要完成全部项目。
[可选检查](SELECTIVE_CHECKS.md) 支持单项、全选与批量处理；每项区分本次结果、来源和限制。

原生时区、地区格式、兼容节点及网络设置的修改，均需预览、确认、读回与复检。
系统授权可能取消或被组织策略拒绝；无法自动处理时给出步骤。模拟适配器、真实 OS
隔离夹具与用户设备观察分别记录，详见 [权限验收](PERMISSION_ACCEPTANCE.md)。

目标是逐项说明测了什么、发现什么问题、如何处理，以及所选使用条件是否合格。
“环境画像”指可追溯的本机资料和观测，不是 Claude 服务端评分。不提供指纹伪造、
自动更换身份或规避地区限制；中文、字体、虚拟机、ASN 标签和单次 IP 变化均不直接
作为封禁风险。

## 八方面证据

| 方面 | 当前提供 |
|---|---|
| 地区与时间 | 实际所在地声明、官方名单、出口国家、时区 / 地区格式目标与时钟偏差 |
| 连接与出口 | HTTP IPv4 / IPv6、连接方式、TLS、服务响应、耗时、ASN 资料、48 小时变化 |
| DNS 与路由 | 解析、hosts、Fake-IP、系统选路、规则；权威 DNS 出口和全进程流量未实现 |
| UDP 与浏览器 | 独立 STUN、浏览器 ICE、两种 HTTP 地址族；未响应不作通过 |
| 设备与浏览器环境 | GPU / 驱动、显示、字体数量、虚拟化线索；当前窗口时区 / 语言 / 图形资料 |
| 客户端与配置 | 桌面 / Code 安装、PATH 多入口、被动版本元数据、配置格式与认证方式存在性 |
| 后台保护 | 代理、TUN、控制接口、守护任务及安装文件的客户端模式一致性 |
| 账号与变化 | 本地事务、磁盘、存档验证与持续变化；文件存在不证明登录有效 |

目录由 [check_catalog.py](../envscope/check_catalog.py) 生成，不计算“账号安全分”。后台没有当前浏览器
资料时会说明缺失，不复用旧观测；不适用条件单列，缺失和参考项不改成通过。

## 上游功能对应

功能对照覆盖检查、状态、切换、跨账号保留、修复、地区 / 客户端设置、
设备 / CLI 信息、临时浏览器、快照、代理诊断、守护 / 看门狗、路由、维护、托盘、
更新、安装 / 卸载和历史。状态由原生能力与已安装维护核心动态决定。

- 原生实现：独立检测、事务账号管理、Code 修复与撤销、目标、历史、用户定时任务、
  托盘、整包更新、两平台临时浏览器、.envsnap 存档、CLI 被动来源和设备资料。
  另有城市地区配置与撤销、10 秒进程守护、Clash Verge 路由维护、macOS 原生 DMG
  兼容，以及 Windows / macOS 60 秒系统时区服务、更新 / 移除 / 基线恢复。所选
  IPv6 接口与 DNS 缓存、客户端 TUN、旧任务迁移和旧软件清理也有原生审核与恢复流程。
- 原版核心或手动处理：尚未原生适配的客户端命令、原版详细信息及兼容维护入口。
  安装和执行需在产品中确认。保留 Mac 原版详细 CLI / 字体入口；原生 CLI 不运行
  PATH 中任意程序，无法从元数据获得的版本会说明需要用户核对。
- 平台边界：Windows Claude 专用语言设置提供手动步骤；DMG 兼容只在 macOS；
  WireGuard 专项面向 Windows。固定随附核心的命令范围与 EnvScope 原生实现分开标注。

上游参考版本与逐项证据以 [完整功能对照](FULL_PARITY_AUDIT.md) 为准。随附 57 文件固定在
`870c4ca0754234965878ef58144d7a755d965037`，原字节和许可不变。原生检测保留多来源证据，
不声称随附安装器已包含新上游所有修复。

## 使用与数据边界

临时浏览器使用已安装 Chrome / Edge / Brave / Chromium 的独立目录，禁用同步和
扩展，限制非代理 UDP；保留真实语言 / 时区。打开前复查网页使用条件，不要求网页
用户安装 Claude 桌面版。未确认进程退出时保留资料；正常退出尝试清理，工具页可
清理已关闭会话。独立清理进程与重启恢复会核对进程归属，无法确认时保留现场并说明原因；
浏览器开关不是防火墙。详见 [临时浏览器](BROWSER_SESSIONS.md)。

加密存档只导出非活动槽位，导入空槽位。Scrypt 固定 N=32768、r=8、p=1；
AES-256-GCM 随机盐 / nonce 并认证头部。先验证标签，再解析 ZIP 和核对文件清单。
拒绝错误密码、截断、改动、重复 / 越界 / 设备名 / 链接 / 歧义路径。暂存资料受限
于当前用户（Windows ACL / macOS 0700），完成后删除，不保证安全擦除。8 GiB /
200000 文件上限；格式与 DMG 不兼容，不保证登录态跨设备迁移。

## 验证

`tests/test_regions.py` 验证 CN / RU 声明、观测、目标与支持出口不能覆盖所在地。
`tests/test_coverage_features.py` 验证加密往返和拒绝写入、临时浏览器参数与清理、
守护模式、CLI 和八方面缺失证据。`scripts/coverage_smoke.py` 在 1024 / 1280 / 1440
窗口完成证据跳转、加密导出、错误密码拒绝、导入、密码清空、模拟浏览器启动与清理。
只用临时资料、网络夹具和假启动器。三架构冻结包另实际运行加密库、窗口、托盘、
更新和用户调度生命周期。

真实 Claude 登录、组织权限、第三方浏览器 WebRTC 策略效果、系统凭据库和长期休眠恢复
仍需具体设备验收。当前 Windows 未进行发布者签名，macOS 为 ad-hoc 签名且未公证；
正式签名是独立的发布接入工作，见 [签名准备](SIGNING.md)。
