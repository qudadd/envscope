# IP 联动、Watchdog 与账号隔离（0.12.0 Alpha）

填写实际地区后，目标表单通过当前所选路由查询 Cloudflare 与 IPinfo。
出口为 US 时只显示美国城市；两个来源的公网 IPv4 与国家一致，且 IPinfo 时区
对应唯一预设时，自动填入建议城市、Windows / IANA 时区、语言与地区格式。
IP 地理数据库可能缺少城市或时区、限流、返回不一致结果，此时需要手动选择。
读取期间修改目标会保留手动输入；旧连接的迟到结果不会覆盖新连接。
这些查询不保存完整 IP，不改写实际所在地，不替代正式环境检测。

## Watchdog

先配置到目标值并检测，再在“持续维护”或首页“保持本次设置”选择守护范围，
预览具体基线后确认一次。用户任务每 5、15 或 60 分钟执行，界面关闭后继续。

- Code 代理与 TLS 字段继续使用原文件备份、字段恢复和复检。
- 时区与当前用户地区格式只恢复预设中已批准且读回一致的值。
- 代理必须有已验证的本机 HTTP / HTTPS 端口。端口离线时，可重开用户选择的
  已安装客户端；可识别路径覆盖 Clash Verge Rev、Mihomo Party、Clash Nyanpasu。
  程序路径和内容摘要变化后需重新批准；没有可识别客户端时明确要求手动处理。
- 唯一可控制 Selector 的具体节点可作为基线；节点漂移后恢复并检查 API TLS。
  检查失败会尝试回到切换前节点。节点名不证明实际出口国家。
- 代理端口在线但上游失败时记录待处理，不反复重启、不强杀程序、不回退直连。
- 每项两次尝试至少间隔 5 分钟，24 小时最多 3 次；反复漂移、目标改变、官方
  地区不合格或未完成的写入记录会暂停自动恢复，重新审核后才能继续。

后台不弹出管理员授权。Windows 时区写入需当前用户具有权限；macOS 从 0.16 起
可在同一个“保持本次设置”方案中明确授权原生系统时区服务，每 60 秒检查。
用户 LaunchAgent 看到系统服务已接管时不会重复写入。更换目标同步更新服务基线，
撤销恢复旧服务和原时区。独立入口可预览安装、更新、移除、恢复未完成事务。
不会在读取检测时安装，不创建节点、订阅或防火墙规则。权限、备份与验收边界见
[系统时区守护](TIMEZONE_SERVICE.md)。

完整事件逐条追加并 fsync 到 `~/.envscope/maintenance/events/YYYY-MM-DD.private.jsonl`，
界面最近 20 条、缓存最近 100 条的轮替不会删除这些日志。系统恢复先记原值和目标，
再执行与读回；进程异常退出时保留 pending 标记，后续暂停而非盲目重试。
日志不上传，停用后保留；长期运行会占用本机空间，可自行归档。
记录是本机操作证据，不是防篡改审计系统或账号可用性保证。

## 账号资料目录

切换使用独立资料目录、逐文件 SHA256 校验、暂存副本、目录重命名与事务恢复记录，
不调用登出接口，不重新生成存档内已有标识。A → B → A 回到 A 自己的资料。
逐个目录重命名是原子操作，整个多目录交换不是单一文件系统事务；失败会回滚，
断电导致不完整事务时保留副本并阻止新切换，尚不自动判定断电后的恢复方向。

`keep-in-workspace.txt` 默认关闭。0.12 起只允许显式指定 `skills/` 内文件，
身份、Cookie、Local State、会话存储和 settings 不允许跨账号复制。旧清单含这些
路径时会停止切换，要求调整清单，保留原资料。切换阶段记录在
`~/.claude-switcher/account-events/`，不记录凭据内容。

系统钥匙串 / 凭据库、硬件与 OS 标识、服务端会话不在资料目录隔离保证内。
本功能不保证每个账号被服务端认定为固定设备；过期登录仍需本人认证。
Code 与浏览器登录不随桌面资料目录切换。

验证使用模拟网络、临时资料目录、注入系统写入与启动器。覆盖 IP 冲突、迟到响应、
手动输入、漂移修复、客户端离线、上游失败、节点回退、冷却、异常中断、日志轮替、
账号身份字节往返。未修改开发电脑网络、时区、账号，未执行真实认证或绕过地区限制。

接口资料：[Cloudflare trace](https://developers.cloudflare.com/fundamentals/reference/cdn-cgi-endpoint/)、
[IPinfo](https://ipinfo.io/developers)。IPinfo 字段与可用性由其服务决定，缺少数据按未知处理。
