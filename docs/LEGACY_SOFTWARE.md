# 旧软件清理与恢复

入口：持续维护 → 旧软件清理。进入页面后只读检查固定安装路径；已识别的程序默认选中，支持单项和全选。展开清单可看到每项的路径、是否安装，以及不能自动处理的原因。账号、凭据、配置和日志均保留。

先预览所选范围，再确认。程序先使用原生组件事务保存、停用并读回旧后台任务，随后重新检查进程、账号事务与文件摘要，将程序移入同一父目录下的 `.envscope-legacy-事务号`。macOS 系统程序通过随包校验的原生辅助程序申请本次管理员权限；不执行已安装的旧脚本。取消授权或任何一项失败都会停止后续处理，保留现场和恢复记录。

| 平台 | 自动处理的固定程序路径 |
|---|---|
| Windows | `~/.claude-switcher/claude-switch.ps1`、`SwitcherUI.ps1`、`claude-bodyguard.ps1`，以及 `~/Desktop/Claude切换器.lnk` |
| macOS 用户程序 | `~/.local/bin/claude-switch.sh`、旧守护脚本及其 `.bak`、三个 `local.*.plist` 安装模板、`~/.claude-switcher/stun-probe.py`、`~/Desktop/Claude切换器.app` |
| macOS 系统程序 | `/Library/Application Support/claude-switcher/` 内固定的 `claude-bodyguard.sh`、`tz-watchdog.sh`、旧版 `claude-switch.sh` |

固定路径加内容标记用于识别安装遗留，并不表示程序经过上游签名认证。App 核对 bundle ID 和可执行入口；Windows 快捷方式只读取属性，目标必须指向旧版固定界面。程序树限制 4096 项、256 MiB，脚本另有 2 MiB 限制。链接、重解析点、硬链接、外部内容、异常归属或权限转为红色手动说明。自定义安装路径、重定向的桌面和未识别的副本请由原用户核对，不扩展搜索后批量删除。

清理前会检查旧界面及已知解释器的命令行；已识别的调度任务可先由迁移事务停用，随后再次检查全部相关程序。手动脚本仍在运行或相关进程无法读取时保留文件；不会按进程名批量强制结束。账号有 `.new`、`.previous` 或未完成交换事务时，先处理账号恢复。

每次移动拒绝覆盖目的路径，并在移动后核对摘要，最后独立读回整批程序与旧任务。移动保留原文件、属性和扩展属性；Windows 另存原 DACL，在恢复时还原继承行为。比较权限时接受系统把继承访问项转换为相同的显式访问项，其他访问权变化仍使方案失效。存档目录受限，里面的原文件保留其既有访问权；不要分享程序存档，其中可能存在旧版自定义配置。

“预览恢复旧程序”按完整事务核对原路径和存档。只恢复匹配的原值；后来出现的新程序、改过的存档、缺失副本或同名冲突均停止处理。恢复后后台任务保持停用，需要时另行预览“恢复原任务”；恢复任务可能立即执行旧脚本，二者不会混为一次隐含授权。上笔存档未恢复前不覆盖恢复入口。

本功能移除所选旧软件入口，不永久销毁存档，也不恢复旧安装器修改过的系统地区、DNS、IPv6、代理规则或客户端偏好。这些设置使用各自带原值、备份与读回的维护入口。原生 EnvScope 守护需要另行审核，移除旧登记本身不代表新守护已启用。

测试范围包括自建临时文件、实际 Shell Link 和 DACL、回环 UI、模拟中断和冲突，以及 CI 唯一命名的惰性调度任务与 macOS root 固定路径夹具。冻结包另做原生文件往返。所有夹具均为自行编写，不执行 vendor 安装器、旧脚本或真实账号；CI 已提升权限不证明系统授权弹窗已由用户验收。
