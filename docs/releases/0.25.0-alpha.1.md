# EnvScope 0.25.0 Alpha

本版完善读取权限与后台守护，并简化 Windows / macOS 桌面操作。

- 读取失败分别显示权限拒绝、组织策略、超时、工具缺失或本版未支持。根据当前失败项目提供授权入口，返回后复检原选择；取消与目标改变不会沿用旧证据。
- Windows 增加受保护的系统时区守护，与 macOS 服务一样按批准基线运行、读回、限频、记录和恢复。后台权限不足不会声称已经保护，也不会反复弹出授权框。
- 守护异常通知去重，重启应用后仍可查看待处理事项。
- 首页集中显示目标、检测、问题与修复方案。侧栏直接进入守护和账号，高级系统操作按需展开；保留选择检查、全选、备份、恢复和工具。
- 更新应用、托盘和导航图标；保留页面滚动与展开说明，防止检测重复提交。设置刷新和保存、教学与 IP 读取之间的时序冲突已修正。
- 安装包使用固定应用标识与版本资源；更新校验包身份、摘要和发布版本。

这是纯开源 Alpha 版本。Windows 包未作发布者签名；macOS 使用构建所需的临时签名，未作 Developer ID 签名或 Apple 公证。完整性与身份一致性校验不等于发布者认证。

自动测试使用隔离配置和模拟网络；原生服务测试使用独立任务和时钟。人工 UAC/TCC 授权、撤权、长期休眠和真实 Claude 登录仍需专用设备或用户环境验证，未计入自动测试通过。具体范围见 [权限验收](../PERMISSION_ACCEPTANCE.md) 与 [桌面验收](../DESKTOP_ACCEPTANCE.md)。

请下载对应系统的 ZIP 并完整解压：Windows x64、macOS Apple Silicon 或 macOS Intel。旧版可保留用于回退；如已配置后台维护，移动应用目录后需重新核对任务入口。
