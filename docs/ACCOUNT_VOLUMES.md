# 独立账号数据卷

EnvScope 的一个账号槽位对应一个完整桌面资料目录。切换按文件系统事务处理：
正常退出 Claude → 校验并封存当前目录 → 准备目标目录 → 目录重命名提交 →
读回校验 → 更新账号标记 → 重新核对启动条件。没有登出接口、Cookie 拼接、
OAuth 内容改写或设备标识重生成。空槽位首次使用仍需本人正常登录。

Windows 客户端可能关闭窗口后仍驻留托盘。默认等待正常退出；若无法退出，
保留原资料并提示处理。可逐次勾选“正常退出失败时允许强制退出”，确认说明会
提示未保存内容可能丢失；此时才允许停止已核对路径、用户和创建时间的桌面进程。
停止后仍需读回确认所有相关进程退出，才能交换目录。该选项不默认开启。

这里的“数据卷”是独立目录，不是虚拟机、磁盘分区或单独的系统用户。
Windows 使用当前用户的 `%APPDATA%/Claude`；macOS 使用
`~/Library/Application Support/Claude`。存档在 `~/.claude-switcher/accounts/<slot>`。
同一时刻只有一个活动桌面目录。Claude Code 与日常浏览器资料不随其交换。

## 隔离及性能

- 原样保留目录内的 Local State、Cookies、Local Storage、IndexedDB 等文件，
  包括其中已有的设备标识、会话和凭据文件。文件含义依客户端版本而定，
  不能把测试夹具命名当作真实客户端登录证明。
- 默认不跨账号合并内容。显式保留清单仅允许 `skills/` 下的通用文件。
- 拒绝符号链接、Windows 重解析点和可共同改写的硬链接；复制前后进行内容校验。
- macOS 优先调用系统 `clonefile`，文件系统支持时使用写时复制；目标文件改写
  不影响原存档。跨卷或文件系统不支持时才回退普通复制；权限、磁盘或其他错误
  保留失败现场。Windows 使用独立文件复制，不使用硬链接“加速”。
- 每次封存/载入都会校验全部内容，因此大目录仍需时间；没有声称整次切换瞬时完成。

## 中断恢复

0.13 起，复制之前先写 v2 事务记录，包含槽位、目录整体校验值、原账号标记
和阶段，不包含 Cookie、OAuth 或设备标识的值。单次目录重命名是提交步骤，
多个目录及标记文件之间并非一个文件系统原子事务。

未完成事务会阻止后续切换与启动。在账号页点“检查恢复方案”，核对后点
“确认恢复资料”：未提交的交换恢复切换前资料；已提交且校验一致的交换完成收尾。
恢复仅在正常退出确认后执行，不自动启动或登录。剩余副本改名为
`.recovered-事务号` 并留在原目录旁，不在恢复时删除；这些副本含敏感资料，
不要公开分享。记录仍写入本机 `~/.claude-switcher/account-events` 按日日志。

方案绑定预览时的内容与标记，五分钟过期。资料发生变化、原件校验不一致、
老版本记录不足、额外遗留副本或退出无法确认时，界面提供手动核对指引。
程序中断和进程退出已用临时目录测试；存储设备损坏或掉电后的实际持久性没有
通过破坏性设备实验验证，不能承诺所有故障均可自动恢复。

## 认证范围

“完整目录被隔离”不等于所有认证要素都在这个目录中。系统钥匙串、DPAPI、
系统硬件信息和服务端会话不由本功能隔离或重建。
[Electron safeStorage 文档](https://www.electronjs.org/docs/latest/api/safe-storage)
说明其加密依赖 macOS Keychain 或 Windows DPAPI；这是客户端架构边界的参考，
不是对当前 Claude 私有认证存储实现的断言。过期或撤销的登录仍需本人认证。

因此只能承诺按校验保留已有本地资料，不能承诺服务端永远认定为同一台设备、
账号安全或跨设备登录迁移。实际客户端不同安装方式及真实账号往返验收仍待完成。

## 验证入口

- `tests/test_accounts.py`：首次收编、往返、失败回滚、保留白名单、并发和导入导出。
- `tests/test_watchdog.py`：不同账号设备 / OAuth / Cookie 夹具字节的连续往返隔离。
- `tests/test_account_recovery.py`：提交边界中断、恢复再次中断、实际测试子进程退出、
  预览过期 / 漂移、禁止猜测、APFS 原生克隆与独立写入、硬链接拒绝。
- `scripts/account_recovery_smoke.py`：离线 Windows / Mac 场景的审核、确认、恢复与解锁。

写时复制实现参考 Apple 的
[clonefile 手册源码](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/man/man2/clonefile.2)。
没有复制 Apple 实现或修改固定的 claude-switcher 上游文件。
