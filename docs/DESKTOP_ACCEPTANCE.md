# 0.8 独立软件与功能回归

产品流程：首次教学 → 一键检测 → 问题与权限分类 → 合并修复方案 → 确认写入 →
自动复检 → 实际 Claude 使用 → 可选日常维护。普通检查无需先配置比较目标或维护核心。

## 本轮修正

- Claude Models 探测改为官方支持的 GET；网页仍使用无认证 HEAD。匿名 API 401
  表示已经到达认证边界，不声称账号可用。403 不再提示用户盲目修改代理端口。
- 系统 HTTP 检测在没有 HTTPS/ALL 代理环境变量时采用已读到的系统 HTTP 代理；
  明确选定后不因失败而退回直连。UDP 与浏览器仍各自保留测量来源。
- Windows 系统信息逐项采集；某一字段失败不丢弃其余字段。
- 使用条件结论与严格隐私判定、账号启动门槛分开。后两者未放宽；
  DNS 权威出口、进程流量关联未实现，IPv6/UDP 无响应不记为通过。
- 只有 PermissionError 才给权限原因。一般 I/O 失败不会伪装成权限不足。
- 独立窗口使用 pywebview，托盘使用 pystray。默认关闭时驻留；托盘未就绪则保留
  正常退出方式。执行中不退出；重复启动唤回已有窗口。
- 更新只信任指定仓库、HTTPS、目标架构与合法版本号。下载同时核对 GitHub 摘要、
  SHA256SUMS、大小及归档路径。安装在旁边的版本目录；校验失败保留当前版本。
  原始下载目录始终保留，应用内回退针对已保存的前一更新版本。

## 可重复验收

| 范围 | 验收入口与证据 | 边界 |
|---|---|---|
| 全部 Python 规则及事务 | `python -m unittest discover -s tests -q` | 临时资料／本机回环，不碰真实账号 |
| 浏览器协议和解释 | `node --test tests/browser.test.mjs` | 合成输入 |
| 教学、方案、修复、复检、撤销、维护、启动 | `python -m scripts.browser_smoke`，1024/1280/1440 | 外部网络均为夹具 |
| 32 项目录、工具、账号往返、历史、断线 | `python -m scripts.usability_smoke`，三种宽度 | 合成 A/B 账号往返，未登录 Claude |
| 软件设置、更新取消/安装/回退、权限取消/入口、状态筛选 | `python -m scripts.desktop_ui_smoke`，三种宽度 | 更新结果夹具；系统授权入口为 mock |
| 更新真实文件安装、摘要错误、损坏、越界、过期、篡改、回退 | `tests/test_desktop_runtime.py` | 临时二进制样本，不执行它 |
| 原生窗口、托盘、隐藏、恢复、退出 | `python -m scripts.native_smoke` | 真实系统窗口；临时 home，无外部探测 |
| 打包程序的窗口、托盘和 worker | `python -m scripts.packaged_smoke <executable>` | 同一隔离场景，从最终二进制执行 |
| 系统计划任务注册、两次自动运行、移除 | `scripts.scheduler_acceptance` | CI 专用临时任务，不改用户配置 |

测试捕获并修复了 Windows 重复启动时读取锁字节的权限错误、页面重复 DOM ID、
目录刷新导致用户正在看的授权说明被折叠，以及取消授权后反馈不明确的问题。

真实账号订阅、实际回复、不同企业权限策略、长期休眠与平台签名/公证不由这些夹具证明。
本轮测试产物放在忽略的 `artifacts/` 目录；公开结果以发布标签的 CI 与校验表为准。
