# 0.7.1 用户操作验收

2026-10-28。本轮从用户反馈的入口出发复现和修改，不以单元测试通过代替使用验证。

| 问题 / 场景 | 修改与验收 |
|---|---|
| 旧页面按钮不可用 | 原 63250 端口已无监听。新增版本与连接状态，断线提示重开启动器；可见页面每 30 秒保持连接 |
| 环境信息看起来没打开 | 以前写入工具页底部。现在显示在按钮下方，自动定位并获得键盘焦点 |
| Mac 没装维护核心就无法看信息 | CLI 和基本设备信息改为原生读取，原版详细检查仍在维护菜单保留 |
| 设备读取失败 | UTF-8 输出，固定只读命令、超时与大小限制；失败保留基础信息并标记部分未取得 |
| 不知道有哪些检查 | 独立“全部检查”导航与首页入口，32 项目录、搜索、分类及状态筛选，每项用途和下一步 |
| 复检失败仍可能误读旧结果 | 检测开始清除旧目录状态，失败标记未核实；历史与后台报告单列来源时间 |
| 不懂 A/B 及账号如何登录 | 四步说明，区分资料代号与注册账号；采用保存当前、首次登录、切换存档的操作名 |
| 连续账号操作点了没生效 | 完成提示早于列表刷新。现在相关按钮在刷新完成前保持禁用 |
| 功能列表读取失败 | 独立提示与重试，环境信息仍可单独读取；不把列表刷新失败说成已完成操作失败 |
| 与原版区别不清楚 | 工具页内嵌对照，完整功能表标出原生、适配和缺口，以及最新上游差异 |

## 已执行的用户任务

`python -m scripts.usability_smoke` 在 1024、1280、1440 像素 Chromium 中执行：

- 检测前查看全部 32 项，筛选基础 14 / 扩展 18、搜索命中与空结果、键盘切换筛选。
- 不做检测、不安装维护核心，分别打开 CLI、设备、浏览器信息和下载诊断包。
- 信息部分缺失、接口失败、功能列表失败及恢复，确认反馈在操作处可见。
- 账号取消、检测前拒绝、检测后 A → B → A，校验两份合成资料完整保留。
- 查历史、重新检测失败，确认旧通过状态不出现在新一轮目录中。
- 服务中断、初次载入即断线、重连、可见页面保活；只读读取不触发账号回调。
- 七个页面无横向溢出、无 JavaScript 页面异常；检查截图中的信息面板、账号及断线状态。

原有 `scripts.browser_smoke` 的教学、修复、备份撤销、代理预览、持续维护、配置漂移恢复、
桌面打开 / 正常重开与取消 / 阻止流程继续保留。测试网络均使用夹具或回环服务；
账号只在临时目录，系统进程和维护任务使用注入回调。

本机 Windows 额外执行实际 CLI 路径与设备资料只读采集，均返回完成，未修改系统。
macOS 信息采集解析通过夹具测试；真实 Mac 图形界面、Safari、账号登录与发送消息未验收。
程序构建和调度测试也不代替实际 Claude 登录、订阅权限或长期连接稳定性验证。

诊断资料、操作日志与原始用户环境不随仓库发布。界面截图仅使用离线合成数据。
