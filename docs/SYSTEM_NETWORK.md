# 系统网络修复与恢复

0.17 将 IPv6 接口修改和 DNS 缓存刷新接入原生修复，无需安装旧维护核心。
普通检测只读。修改前列出具体接口及影响，确认后才申请本次系统授权。

## 怎么使用

1. 确认实际地区、使用方式和连接目标，完成一次新检测。只有明确选择“关闭 IPv6”时才生成关闭方案；仅观察或允许网段模式保留原设置。
2. 检测页的“一键检测与修复”会将已测到的 IPv6 / DNS 问题纳入方案。“全部检查”可勾选对应项目批量处理，不会顺带修改未选择的项目。
3. 需要自己选接口时，打开“持续维护 → 网络设置与恢复”，点击“读取网络接口”。默认勾选正在使用且启用 IPv6 的接口，也可全选或取消全选。
4. DNS 缓存刷新是独立选项。预览后审核具体影响，点击“确认修改并复检”，在系统窗口完成授权。没有密码字段，后台不会申请网络修改授权。
5. 修改后独立读取设置，再检测解析、连接与出口；接口列表自动刷新。设置已读回不等于 Claude 已能登录或所有流量已接管。

当前报告和方案须在 90 秒内，目标、接口原配置及恢复记录不得在预览后改变。
实际地区未确认、地区条件不合格或存在未完成网络事务时，不生成新的网络修改。

## 修改范围

Windows 根据稳定网卡 GUID 核对当前接口，通过系统 NetAdapter 模块修改该接口的
`ms_tcpip6` 绑定。保留并核对其他绑定。系统 API 可能连带改变其他绑定，此时停止、
保留记录并转人工核对，不把不可归因的变化强行覆盖回去。

macOS 使用 SystemConfiguration API，只切换选中网络服务的 IPv6 启用状态；
保留手动 IPv6 地址、前缀和其他原配置，不按固定的 Wi-Fi 名称批量重置。
只执行本次事务，不安装新的网络后台服务。

DNS 操作仅清空本机解析缓存，不替换 DNS 服务器、不修改 hosts，也不清理代理客户端
自己的缓存。缓存内容不能撤销；后续查询会重新建立。刷新命令完成仍需解析复检，
不能当作权威 DNS 出口或零泄漏证明。

## 失败与恢复

写入前保存原值和受保护的事务记录。修改后必须独立读回，执行返回零本身不算成功。
写入失败时尝试恢复本次 IPv6 变化，并验证恢复结果；DNS 刷新失败单独记录。
进程中断后保留 `prepared` / `partial` 记录，阻止覆盖它。

点击“预览恢复原设置”，审核后确认。恢复只使用最新事务的原值，不继续尝试失败的
新配置；原备份和按日事件保留。接口消失、其他配置已被后续修改或记录归属不同
时标红，停止自动覆盖。

不能自动恢复时：先关闭受影响应用的未保存工作，在 Windows 网络适配器属性或
macOS 系统设置的网络服务中核对 IPv6；请管理员对照受保护备份处理后重新检测。
不要删除未完成记录来假装恢复完成；它可能仍是恢复原值的唯一证据。

Windows 记录在 `%ProgramData%\EnvScope\network`；macOS 在
`/Library/PrivilegedHelperTools/io.qudadd.envscope.network`。备份和按日事件仅管理员 /
系统可写，私有历史限制读取；界面只取得必要状态，不把完整网络原配置或二进制数据
写入报告。退出 EnvScope 后记录仍保留。

## 权限与验证范围

Windows 使用固定的内存编码命令申请 UAC，写入前重新复制并校验方案数据摘要；
不会以管理员身份执行用户可改写的 `.ps1`。模块只从系统目录导入。
macOS 将本版本原生辅助程序与方案复制至 root 目录、再次核对摘要并取得内核锁，
不以 root 执行 Python 或用户脚本。两平台都拒绝重定向目录和不可信恢复权限。

回归测试使用内存、临时文件或独立 CI 路径中的假网卡。CI 真实执行权限、独占锁、
备份、写入读回、中断恢复与失败处理；Mac 两种架构和 Windows 均有独立验收。
只读比较真实网卡前后状态，测试不改真实网卡、不清理真实 DNS 缓存。
界面走查覆盖 1024 / 1280 / 1440 宽度，系统授权为注入夹具。

真实用户设备的授权弹窗、网络瞬断、VPN 驱动差异、睡眠恢复及实际 Claude 登录仍需
设备验收。原生代理客户端 TUN 持久化、多客户端语言设置和旧组件可逆迁移尚未全部完成，
完整进度见 [核对表](FULL_PARITY_AUDIT.md)。

系统 API 依据：[Microsoft Set-NetAdapterBinding](https://learn.microsoft.com/en-us/powershell/module/netadapter/set-netadapterbinding)、
[Apple SCNetworkProtocolSetEnabled](https://developer.apple.com/documentation/systemconfiguration/scnetworkprotocolsetenabled(_:_:))。
