    账号

    为 Claude 桌面版保存不同的本机登录资料。这里只管理存档，登录仍在 Claude 中完成。

    第一次怎样使用

    1. 只有一个账号：正常在 Claude 登录即可，无需添加槽位。
    2. 需要多个账号：先给 A 命名，检测通过后点“保存当前资料到 A”。
    3. 给 B 命名，点“首次登录”；现有资料会保留在 A，在新打开的 Claude 中登录自己的另一个账号。
    4. 以后用“切换并打开”返回已有存档。请先保存工作；切换会退出桌面应用。

    A、B 是资料文件夹的代号，不是邮箱或已注册账号。添加名称不会创建 Claude 账号，也不会登录。Claude Code 和浏览器的登录不随此处切换。

    先检测环境；切换时还会重新检测。

    代号使用英文字母、数字、下划线或短横线，以字母或数字开头；最多 32 字符。可先使用现有的 A、B。

    本地目录备份与导入

    目录包含登录资料，未加密。仅支持非活动账号导出、空槽位导入；不能保证跨系统迁移登录状态。macOS 的加密 DMG 位于工具页。

    与 claude-switcher 有什么区别
    EnvScope 原生实现检测和资料交换，系统级修复与进程守护仍通过原版维护核心。随附源码不等于已安装维护核心。
    用途claude-switcherEnvScope
    检查与解释14 类环境检查14 项基础 + 18 项扩展，另列独立测量；提供用途和下一步
    桌面账号Mac A–D；Windows A/B 界面可命名的动态槽位，校验复制、失败回滚、切换前复检
    配置修复偏重系统、代理和路由增加 Code 配置预览、备份撤销与自动复检；系统修复仍接入原版
    长期保持进程守护；Mac 时区守护增加定时复检、历史与批准的 Code 字段恢复；进程守护需另装原版核心
    仍有边界Mac 有加密 DMG、临时浏览器等这些 Mac 工具仍由原版提供；Windows 尚无原生等价功能，定时复检也不是断网保护
    对照随附固定版本 870c4ca；2026-10-28 核对上游 f20a38a，后续 Windows 控制接口回退修复尚未纳入随附核心。
