    与 claude-switcher 的功能对照

    正在读取可用功能…

    账号

    每个账号使用独立本地数据卷。切换时正常退出 Claude，完整封存并载入对应资料；保留已有身份与会话，不调用登出接口。

    数据隔离与切换记录

    各账号保存其目录内已有的会话、设备标识与本地状态。交换前退出 Claude，逐文件校验暂存副本，再以目录重命名提交；失败回滚，未完成事务保留恢复资料并停止启动。切换事件按日保存在 ~/.claude-switcher/account-events，不记录凭据内容。跨账号保留仅限显式选择的 skills/ 文件。

    系统钥匙串、系统凭据库和服务端会话状态不等于资料目录内容，登录过期仍可能需要本人重新认证。本功能不保证服务端设备判断、账号稳定性或跨机器登录迁移。

    第一次怎样使用

    1. 只有一个账号：正常在 Claude 登录即可，无需添加槽位。
    2. 需要多个账号：先给 A 命名，检测通过后点“保存当前资料到 A”。
    3. 给 B 命名，点“首次登录”；现有资料会保留在 A，在新打开的 Claude 中登录自己的另一个账号。
    4. 以后用“切换并打开”返回已有存档。请先保存工作；切换会退出桌面应用。

    A、B 是资料文件夹的代号，不是邮箱或已注册账号。添加名称不会创建 Claude 账号，也不会登录。Claude Code 和浏览器的登录不随此处切换。

    先检测环境；切换时还会重新检测。

      代号使用英文字母、数字、下划线或短横线，以字母或数字开头；最多 32 字符。可先使用现有的 A、B。

      加密备份与恢复

      Windows / macOS 均可使用 .envsnap 加密存档。先切换到其他账号，再导出非活动槽位；导入只能选择空槽位。密码不保存，丢失无法恢复。存档不保证登录凭据能跨设备或系统迁移。

      .envsnap 使用认证加密，可导入任意空槽位。

      高级：未加密目录备份与导入

      目录包含登录资料，未加密。仅支持非活动账号导出、空槽位导入；不能保证跨系统迁移登录状态。原版 DMG 可在上方选择备份格式。

      与 claude-switcher 有什么区别
      EnvScope 原生提供逐项检查、配置预览与恢复、独立账号资料、加密存档、临时浏览器、托盘和完整软件更新。持续维护提供基线恢复、单独批准的 10 秒进程守护，以及可授权的 Mac 60 秒系统时区守护。
      Clash Verge 置顶路由、Mac 系统时区服务和原版加密 DMG 兼容已原生实现。系统网络深度修复、其他客户端适配和旧组件迁移仍需维护核心或手动处理；具体能力与验收范围见环境全览。
